# Versión 01 · Landing con material de stock

Primera versión de la landing, la que se aprobó a nivel de diseño antes de
tener el material real del estudio. Se conserva como referencia para comparar
contra la versión actual, que vive en la raíz del proyecto.

Todo el contenido de esta versión es de relleno: fotos de Pexels, video y
música de Mixkit, precios de ejemplo y una lista de equipo inventada. No debe
publicarse ni usarse como fuente de información del estudio.

## Verla en local

Desde la raíz del proyecto:

```bash
npm run dev:v1
```

Abre en `http://localhost:5174`.

## Qué cambió en la versión actual

- Fotos, equipo, tarifas, portafolio, clientes y reseñas reales del estudio.
- Hero con slideshow de fotos del estudio en lugar de video de stock.
- Salas con galería y una sección de amenidades.
- Catálogo de equipo con fotos, organizado por función.
- Portafolio de trabajos con video, en lugar de solo audio.
- Cotizador oculto mientras se itera.
